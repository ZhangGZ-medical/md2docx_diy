# md2docx_diy

Markdown文档 → 中文DOCX格式转换工具。

## 功能

将Markdown文件转换为排版精良的A4 Word文档（支持横版/纵向），完整支持中文格式和各类Markdown语法。

## 支持的格式

| Markdown语法 | DOCX输出效果 |
|---|---|
| `#` ~ `######` 标题 | 1-6级标题，黑体，深蓝色，带底边线 |
| `**粗体**` | 黑体加粗 |
| `*斜体*` | 楷体斜体 |
| ` ```code``` ` 代码块 | 灰色背景代码框 |
| `> 引用块` | 浅蓝背景 + 蓝色左边框 |
| `| table |` 表格 | 深蓝表头 + 交替行背景色 |
| `[text](#anchor)` 链接 | 保留文本，生成Word书签 |

## 排版规格

- 页面：A4横版/纵向可切换
- 正文：宋体10.5pt，行距1.15倍
- 标题：黑体，16pt → 9pt递减
- 页眉页脚：文件名自动嵌入

## 文件结构

```
md2docx_diy/
├── SKILL.md          # 技能定义与使用说明
├── md2docx_diy.py    # 主转换脚本
└── README.md         # 本说明文件
```

## 依赖

- Windows（依赖SimHei/SimSun/楷体系统字体）
- `python-docx`
- 输入MD文件UTF-8编码
